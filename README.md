# Biotex - Contratos

Módulo para **Odoo 19 Enterprise** · Alphaqueb Consulting SAS · Proyecto Biotex (fase 1).

Contratos por institución y razón social: claves, cantidades, precios, monto; avance por monto y por clave; alertas de saldo

## Dependencias
`biotex_base`, `biotex_catalog`, `sale_management`, `stock`

## Instalación
1. Clonar dentro del `addons_path` del servidor Odoo 19 junto con los demás módulos `biotex_*`.
2. Actualizar lista de aplicaciones e instalar `biotex_contract`.
